Protokol Perlindungan Anonimitas

BEM FMIKOM UNUGHA menerapkan perlindungan data tingkat tinggi untuk mendorong partisipasi kritis tanpa kekhawatiran intimidasi:

  • Pemisahan Data Kredensial: Pengirim dengan opsi "Anonim" diputus relasi datanya dari nomor induk mahasiswa di basis data relasional.
  • Audit Trail Terbatas: Hanya Superadministrator yang dapat mengakses log dekripsi dalam keadaan eskalasi hukum darurat.
  • Penandaan Publik Transparan: Semua tindak lanjut tetap dipublikasikan di kanal pengumuman advokasi tanpa menyertakan metadata personal.
