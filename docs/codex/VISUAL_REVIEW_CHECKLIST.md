# Visual Review Checklist

For each route with Stitch reference:
- [ ] Correct screen reference opened.
- [ ] Desktop/mobile breakpoint behavior matches reference intent.
- [ ] Typography family/size/weight/hierarchy.
- [ ] Navy/amber/neutral semantic palette.
- [ ] Border radius and shadow tier.
- [ ] Page/container spacing.
- [ ] Public vs admin density appropriate.
- [ ] Navigation active state and grouping.
- [ ] Buttons/inputs/badges/tables/cards consistent.
- [ ] Long text truncation/wrapping safe.
- [ ] Loading/empty/error/forbidden states styled consistently.
- [ ] Mobile tables transformed to cards/list where intended, not merely shrunk.
- [ ] Touch targets reasonable at 360/390/412.
- [ ] No accidental horizontal overflow.
- [ ] Permission-hidden menus/actions match role.
- [ ] No out-of-scope UI introduced.

Record screenshot evidence during Phase 11 or earlier when practical.
