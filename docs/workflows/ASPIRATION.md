# Workflow — Aspirations

Public form requires subject/message; name/NIM/email optional. User selects target division or mapped category.

Status lifecycle only:
`PENDING -> READ -> RESOLVED`.

- KEPALA_BIDANG sees only aspirations routed to own division.
- BPH and SUPER_ADMIN can see cross-division.
- Public submit endpoint is rate-limited.
- Do not turn this into chat, SLA/ticketing, or multi-stage approval in v1.4.
